# NewYouGo

[NewYouGo](https://newyougo.com/) is a browser-based workspace for creating and editing AI images, videos, and music. This repository contains a public product guide and example creative workflows.

**[Open NewYouGo](https://newyougo.com/) · [Pricing](https://newyougo.com/pricing) · [Documentation](https://newyougo.com/docs) · [Blog](https://newyougo.com/blog)**

## What you can create

- **Images:** generate from text or reference images and edit existing images with multiple AI models.
- **Video:** turn text prompts or reference images into video clips.
- **Music:** generate music from prompts with models including ACE Step 1.5 and MiniMax Music.
- **Image tools:** remove backgrounds, upscale images, and explore LoRA styling.

## Quick start

1. Visit [newyougo.com](https://newyougo.com/) and sign in.
2. Choose an image, video, music, or editing tool.
3. Select a model, enter a prompt, and add a reference image if the selected tool supports it.
4. Review the credit cost before generating.
5. Refine one part of the prompt at a time, then download the result.

## Example creative workflows

### Product visual

Start with a clear product photo. Use image editing to explore a background, lighting, or composition, then inspect the product shape and text before using the result.

Example prompt to adapt:

> A studio product photograph of a ceramic coffee cup on a pale stone surface, soft window light from the left, neutral background, room for a headline on the right.

### Short video concept

Create or upload a reference image, choose an image-to-video model, and describe one main movement. Keep camera movement and subject motion simple for the first version.

Example prompt to adapt:

> A slow camera push toward the coffee cup as gentle steam rises, steady framing, warm morning light.

### Music sketch

Describe the intended mood, instrumentation, and pace, then generate variations to compare.

Example prompt to adapt:

> A calm instrumental sketch with soft piano, warm bass, and light percussion for a relaxed morning scene.

These are illustrative prompts, not output quality guarantees. Available settings depend on the selected model.
